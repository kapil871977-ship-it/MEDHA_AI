# Deploying MEDHA AI (Render + Vercel)

Backend (FastAPI) runs on **Render**; frontend (React PWA) runs on **Vercel**.
Deploy the backend first, then point the frontend at it, then allow the frontend's
URL in the backend's CORS.

Config already in this repo:
- `render.yaml` — Render Blueprint for the backend
- `backend/.python-version` — pins Python 3.11.9
- `frontend/vercel.json` — SPA rewrites + service-worker cache header

---

## 0. Prerequisites

- The repo is pushed to GitHub (see the "commit and push" steps).
- An OpenAI API key and/or a Google Gemini API key.
- Free accounts on [Render](https://render.com) and [Vercel](https://vercel.com).

---

## 1. Backend → Render

1. Render → **New** → **Blueprint**.
2. Connect your GitHub account and pick this repository. Render detects `render.yaml`
   and proposes a service named **medha-ai-backend**. Click **Apply**.
3. Open the service → **Environment**, and set the values that aren't auto-filled:
   - `OPENAI_API_KEY` — your OpenAI key (or leave blank and set `GOOGLE_API_KEY`).
   - `GOOGLE_API_KEY` — your Gemini key (optional if OpenAI is set).
   - `ALLOWED_ORIGINS` — leave blank for now; you'll set it in step 3 once you have the Vercel URL.
   - `AUTH_SECRET_KEY` — already generated by Render (leave it).
4. Wait for the deploy to finish, then confirm health:
   `https://medha-ai-backend.onrender.com/health` should return
   `{"status":"ok", ... "llm_available": true}`.
5. **Copy the backend URL** (e.g. `https://medha-ai-backend.onrender.com`) — you need it next.

> **Accounts persistence (important):** the free plan wipes the filesystem on every
> deploy, so signups in `users.db` are lost on redeploy/restart. For durable accounts,
> edit `render.yaml`: set `plan: starter` and uncomment the `AUTH_DB_PATH` +
> `disk` blocks, then redeploy. (Alternatively, migrate auth to Postgres.)

---

## 2. Frontend → Vercel

1. Vercel → **Add New** → **Project**, and import the same GitHub repo.
2. Set **Root Directory** to `frontend` (click *Edit* next to Root Directory and choose it).
   Framework preset auto-detects as **Create React App** — leave build/output defaults.
3. Under **Environment Variables**, add:
   - `REACT_APP_API_URL` = the backend URL from step 1 (e.g. `https://medha-ai-backend.onrender.com`)
     — no trailing slash.
4. Click **Deploy**. When it finishes, **copy the frontend URL**
   (e.g. `https://medha-ai.vercel.app`).

> CRA reads `REACT_APP_*` at **build** time. If you change `REACT_APP_API_URL` later,
> trigger a redeploy so it takes effect.

---

## 3. Connect the two (CORS)

1. Back in Render → the backend service → **Environment**:
   - Set `ALLOWED_ORIGINS` = your Vercel URL (e.g. `https://medha-ai.vercel.app`).
     For multiple domains, comma-separate them (e.g. `https://medha-ai.vercel.app,https://www.yourdomain.com`).
2. Save — Render redeploys automatically.

---

## 4. Verify

Open the Vercel URL and run the full flow over HTTPS:
1. Sign up (choose "Account banayein"), then log in.
2. Fill the birth details → open the kundli → confirm the reading loads.
3. Try a Tezi-Mandi prediction.
4. Confirm the PWA install prompt: desktop Chrome/Edge shows an **install** icon in the
   address bar; on iPhone, Safari → **Share → Add to Home Screen**.

If the kundli fails to load, the usual causes are: `REACT_APP_API_URL` not set (or set with a
trailing slash), `ALLOWED_ORIGINS` not matching the exact Vercel URL, or the LLM keys missing on Render.

## Environment variables reference

### Backend (Render)
| Variable | Purpose |
|----------|---------|
| `OPENAI_API_KEY` / `GOOGLE_API_KEY` | At least one required (OpenAI primary, Gemini fallback) |
| `AUTH_SECRET_KEY` | Signs auth tokens (Render auto-generates) |
| `ALLOWED_ORIGINS` | Comma-separated allowed frontend origins |
| `AUTH_ENFORCE` | `true` to require login on API endpoints |
| `RATE_LIMIT_PER_MINUTE` | Per-IP request cap (0 disables) |
| `AUTH_DB_PATH` | SQLite path; point at a persistent disk in production |
| `HOST` / `PORT` | Bind host/port (Render provides `$PORT`) |

### Frontend (Vercel)
| Variable | Purpose |
|----------|---------|
| `REACT_APP_API_URL` | Full HTTPS URL of the Render backend |

---

## Custom domains (optional)

- **Vercel:** Project → Settings → Domains → add your domain and follow the DNS steps.
- **Render:** Service → Settings → Custom Domains.
- After adding a custom frontend domain, add it to `ALLOWED_ORIGINS` on Render.
